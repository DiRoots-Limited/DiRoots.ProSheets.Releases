Da Revit a PDF, DWG, DGN, DWF, NWC, IFC e immagini.

ProSheets è un plugin per Autodesk Revit che consente di esportare in batch viste e tavole nei formati PDF, DWG, DGN, DWF, NWC, IFC e immagine (JPEG, PNG, TIFF, ecc.).

### Funzionalità principali
- Esportazione da Revit in PDF, DWG, DGN, DWF, NWC, IFC e formati immagine.
- Esportazione con un nome file personalizzato creato tramite parametri Revit o personalizzati (ad es. nomeTavola-numeroTavola.pdf).
- Salvataggio dei nomi file personalizzati e delle impostazioni di esportazione nei profili.
- Rilevamento automatico del formato carta.
- Rilevamento automatico dell'orientamento (verticale e orizzontale).

### Altre funzionalità
- Generazione di report per ogni esportazione (XLSX e CSV).
- Utilizzo di variabili di ambiente (ad es. per creare una sottocartella con la data corrente).
- Creazione di sottocartelle per formato di file.
- Unione di formati e orientamenti carta diversi in un unico documento PDF.
- Ordinamento dei disegni durante l'unione in un unico documento PDF.
- [Premium]* Pianificazione delle esportazioni.
- [Premium]* Collegamento delle immagini durante l'esportazione di file DWG (le immagini possono essere incorporate come oggetti OLE anziché come riferimenti esterni).

(*) [Passa a Premium](https://diroots.com/revit-plugins/quote-request/)

### Versioni di Revit supportate
2018, 2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026 e 2027.
