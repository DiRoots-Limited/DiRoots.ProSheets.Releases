ProSheets는 뷰와 시트를 PDF, DWG, DGN, DWF, NWC, IFC 및 이미지(JPEG, PNG, TIFF 등)로 일괄 내보내는 Autodesk Revit용 플러그인입니다.

### 주요 기능
- Revit에서 PDF, DWG, DGN, DWF, NWC, IFC 및 이미지로 내보내기.
- Revit 매개변수 또는 사용자 매개변수로 만든 사용자 지정 파일 이름을 사용하여 내보내기(예: 시트이름-시트번호.pdf).
- 사용자 지정 파일 이름과 내보내기 설정을 프로필에 저장.
- 용지 크기 자동 감지.
- 방향(세로 및 가로) 자동 감지.

### 기타 기능
- 각 내보내기에 대한 보고서 생성(XLSX 및 CSV).
- 환경 변수 사용(예: 현재 날짜로 하위 폴더 생성).
- 파일 형식별 하위 폴더 생성.
- 서로 다른 용지 크기와 방향을 하나의 PDF 문서로 결합.
- 도면을 하나의 PDF 문서로 결합할 때 순서 지정.
- [Premium]* 내보내기 예약.
- [Premium]* DWG 파일 내보내기 시 이미지 바인딩(외부 참조 대신 OLE 개체로 이미지 삽입 가능).

(*) [Premium으로 업그레이드](https://diroots.com/revit-plugins/quote-request/)
