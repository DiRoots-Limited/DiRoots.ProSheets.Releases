ProSheets — это плагин для Autodesk Revit, предназначенный для пакетного экспорта видов и листов в PDF, DWG, DGN, DWF, NWC, IFC и форматы изображений (JPEG, PNG, TIFF и др.).

### Основные возможности
- Экспорт из Revit в PDF, DWG, DGN, DWF, NWC, IFC и форматы изображений.
- Экспорт с пользовательским именем файла, созданным на основе параметров Revit или пользовательских параметров (например, имяЛиста-номерЛиста.pdf).
- Сохранение пользовательских имен файлов и настроек экспорта в профилях.
- Автоматическое определение размера бумаги.
- Автоматическое определение ориентации (книжная и альбомная).

### Другие возможности
- Создание отчётов для каждого экспорта (XLSX и CSV).
- Использование переменных среды (например, для создания вложенной папки с текущей датой).
- Создание вложенных папок по формату файла.
- Объединение разных размеров и ориентаций бумаги в одном документе PDF.
- Упорядочивание чертежей при их объединении в один документ PDF.
- [Premium]* Экспорт по расписанию.
- [Premium]* Внедрение изображений при экспорте файлов DWG (изображения можно встроить как объекты OLE вместо внешних ссылок).

(*) [Перейти на Premium](https://diroots.com/revit-plugins/quote-request/)

### Поддерживаемые версии Revit
