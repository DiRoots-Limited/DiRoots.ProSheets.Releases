ProSheets 是一款 Autodesk Revit 外掛程式，可將視圖和圖紙批次匯出為 PDF、DWG、DGN、DWF、NWC、IFC 和影像（JPEG、PNG、TIFF 等）。

### 主要功能
- 將 Revit 匯出為 PDF、DWG、DGN、DWF、NWC、IFC 和影像。
- 使用由 Revit 參數或自訂參數組成的自訂檔案名稱匯出（例如：圖紙名稱-圖紙編號.pdf）。
- 將自訂檔案名稱和匯出設定儲存至設定檔。
- 自動偵測紙張尺寸。
- 自動偵測方向（直向和橫向）。

### 其他功能
- 為每次匯出產生報告（XLSX 和 CSV）。
- 使用環境變數（例如，建立以目前日期命名的子資料夾）。
- 依檔案格式建立子資料夾。
- 將不同的紙張尺寸和方向合併到一個 PDF 文件中。
- 將圖面合併為單一 PDF 文件時進行排序。
- [Premium]* 排程匯出。
- [Premium]* 匯出 DWG 檔案時綁定影像（可將影像嵌入為 OLE 物件，而不使用外部參考）。

(*) [升級至 Premium](https://diroots.com/revit-plugins/quote-request/)

### 支援的 Revit 版本
2018、2019、2020、2021、2022、2023、2024、2025、2026 和 2027。
