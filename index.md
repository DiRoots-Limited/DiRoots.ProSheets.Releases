# ProSheets | Autodesk Revit Plugin.

![ProSheets Logo](/assets/images/ProSheets-Icon-150x150-1.png)

ProSheets is an Autodesk Revit Add-in to export Views and Sheets to PDF, DWG, DGN, DWF, NWC, IFC, IMG (BMP, JPEG, PNG, TARGA, TIFF) and XML.

## Core Features

- Batch Export Sheets/Views to PDF, DWG, DGN, DWF, NWC, IFC, IMG (BMP, JPEG, PNG, TARGA, TIFF) and XML.
- Export sheets and views from linked models together with the main model (premium feature)
- Auto detection of paper size and orientation (based on the Title Block family Sheet Width and Height)
- Custom Parametric Filename (e.g., Sheet Name + Sheet Number + Revision Number). Plus: custom parameters and separators
- Save the export settings to Profiles
- Import Profiles from a any location (e.g., shared folder, network location, etc.)
- Schedule exports with date/time and repeat frequency to be made automatically, even when Revit is closed (premium feature)
- Available in English, French, German, Spanish, Portuguese (Brazil), and Chinese (Simplified). ProSheets follows Revit's language by default; to choose another language, go to File > Options in Revit and open the "DiRoots" tab
